# Reproducible Research in Bioinformatics and Computational Biology

Material for the advanced module of the PhD course *Reproducible Research in Bioinformatics and Computational Biology*, a collaboration between SLU's GS-VMAS Graduate School and MedBioInfo (2026 edition).

The aim of this module is to share how to use bioinformatics tools in a reproducible and scalable way. We will use environments, containers, and established pipelines so that you can run these analyses on any operating system, as well as on systems that are not high performance computing clusters. And first and foremost: these tools and techniques can be used regardless of which type of bioinformatics you are ultimately working with.

## Content:
- **Course website:** https://amrei-bp.github.io/Reproducible_Research/ (source in `homepage/`)
- **Nextflow RNA-seq pipeline:** [`pipeline/`](pipeline/), with step-by-step teaching scripts, solutions, and a GitHub Actions test

The website will remain active after the course so that you have access to the material for future reference.
